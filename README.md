- Descripción

Este proyecto presenta un dashboard interactivo para el análisis de la inflación entre 1980 y 2026. La aplicación permite explorar la evolución histórica de la inflación mediante visualizaciones dinámicas, facilitando la identificación de tendencias, períodos de alta volatilidad y cambios estructurales a lo largo del tiempo.

El dashboard fue desarrollado utilizando R para el procesamiento y análisis de datos, y exportado como una aplicación HTML interactiva para su visualización en navegadores web.
